# Vael 2.1.0

**Heartbeat — планировщик сообщений в сессию:**

- Новый модуль Pyre: отправляет `[FREE]` в активную сессию по расписанию через PTY
- Три режима: разовый через интервал, разовый на точное время, повторяющийся
- Настраиваемый шаблон: `<timefromlastmessage>`, `<time>`, `<date>`, `<text>`, `<text?, >`
- Очередь в `~/.vael/heartbeat-queue.json` переживает перезапуск приложения
- Отправка откладывается, пока сессия занята — до 5 минут, затем принудительно
- Запуск блокируется без активного PTY: проверяется живость процесса, а не статус idle

**CLI `vael` — управление из терминала:**

- `vael wake 5min` / `--at 09:00` / `every 30min` — постановка задач в очередь
- `vael hb on/off`, `hb session this`, `hb template` — состояние и настройки модуля
- `vael tg "текст"` — отправка сообщения в Telegram с подтверждением в stdout
- `vael status`, `vael wake list/cancel/clear`
- Команды передаются через `~/.vael/heartbeat-control.json`, опрос раз в секунду

**Интерфейс:**

- Панели Telegram и Heartbeat переписаны: статус модуля, закреплённая кнопка
  сохранения, индикатор состояния PTY выбранной сессии, список активных сессий
- Telegram: определение chat_id через `getUpdates`
- Список модулей в сайдбаре: иконка, название, состояние
- Уведомления: превью карточек, выбор угла, масштаб, звук
- Индикация трафика в обход VPN
- Кнопка разворота свёрнутого сайдбара в шапке

**Под капотом:**

- Модели Claude 5 (Opus 5, Sonnet 5), миграция сохранённых ID
- Общее хранилище сессий `~/.vael/sessions` через junction
- Сбор статистики использования, проверка сетевого маршрута

**Исправлено:**

- Панель Pyre не переключалась между модулями: `activeModuleId` хранился в двух
  независимых состояниях — в `App.tsx` и в `PyreWrapper`
- Флаг `enabled` расходился с реальным состоянием модуля: `start()`/`stop()`
  управляли таймером, но не записывали настройку
- Повторяющиеся задачи теряли отправку при занятой сессии: сдвиг `nextAt` сливал
  отложенную отправку со следующим циклом
- Дрейф интервала: следующее срабатывание считалось от момента доставки вместо
  планового времени
- Автозапуск Heartbeat не срабатывал: на старте приложения PTY ещё не подняты,
  и проверка живости отклоняла запуск
