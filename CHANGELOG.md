# Vael 3.0.0

**Чат-режим:**

- Любую сессию можно показать чатом: переключатель «Терминал / Чат» в шапке. Под капотом один живой `claude -p` в режиме stream-json на сессию, история общая с терминалом
- Ответ печатается по мере генерации, своё сообщение появляется сразу и пульсирует до ответа
- Шаги инструментов сворачиваются в строку (`21 шаг · Bash ×12, Read ×5`), `Edit` и `Write` показываются диффом с `+N −M`
- Строка хода под ответом: время, новый вход, чтение кэша, выход — с подсказками
- Блоки кода с языком и копированием, копирование и время у каждого сообщения, кнопка «вниз»
- Модель, мышление и режим разрешений — у композера. Список моделей берётся из CLI
- Вложения: картинки, PDF, текстовые файлы. Слэш-команды через `/`
- Ссылки открываются в браузере по умолчанию (только http, https, mailto)

**Компакт:**

- `/compact` — карточка: во время сжатия таймер, после — было → стало (`439k → 17k · −96%`)
- Список файлов, которые CLI вернул в контекст: целиком или только именем
- Полный пересказ, который теперь помнит модель, — в карточке по клику
- ПКМ по сессии → «Пересказы»: все сжатия сессии с текстом
- `vael summary <uuid|this> [N|last|all]` — то же из терминала

**Интерфейс:**

- Каркас переделан: единая верхняя линия 44px, поиск (`Ctrl+K`) и группы по датам в сайдбаре, точки-статусы сессий, тонкий рейл
- Тема Claude перекрашена в графит
- Свой логотип вместо заглушек; иконка в 9 размерах, упрощённый рисунок для 16–32px
- Экран новой сессии и продолжения переделан
- Лимиты в сайдбаре с отсчётом до сброса: `5ч · 50% (4ч 30м)`, `7д · 18% (3д 5ч)`
- Страницы «Аккаунты» и «Статистика» заново: плитки лимитов, график по дням и часам, модели, топ сессий, тепловая карта за 26 недель
- Удаление сессии — в корзину Windows, с подтверждением

**Первый запуск и аккаунты:**

- Проверка Claude Code идёт первой, до аккаунтов. Новый экран установки
- После автоустановки перезапуск не нужен: claude ищется заново, в том числе в `~/.local/bin`
- Вышли из всех аккаунтов — экран «Войдите снова»
- Последний аккаунт можно удалить, после этого — экран первого запуска
- Кириллица в имени аккаунта транслитерируется (`основной` → `osnovnoy`)

**Под капотом:**

- Статистика считается инкрементально: помнит смещение каждого jsonl, читает асинхронно. Повторный подсчёт ~6 мс вместо зависания интерфейса
- Память: правила загрузки в `memory.config.json` (always / recent / never / tags), граф памяти
- Таймаут автоустановки Claude Code — 5 минут

**Исправлено:**

- `npm run dev` падал: 45 импортов типов без `import type` (в сборке вырезались, dev-сервер — нет)
- В dev история чата не загружалась: StrictMode запускал эффект дважды, и первая отменённая загрузка помечала историю загруженной
- Карточка компакта дублировалась каждые ~30 с: CLI повторяет `status: compacting`, пока идёт сжатие
- В истории карточка компакта стояла над командой `/compact`
- Добавленные строки в диффе были того же оттенка, что удалённые
- Окно входа вызывало `claude` из устаревшего PATH и не находило свежеустановленный CLI
- Кириллица в имени аккаунта превращалась в `____`
- Экран первого запуска нельзя было закрыть: не было кнопок окна

# Vael 2.1.0

**Heartbeat — планировщик сообщений в сессию:**

- Новый модуль Pyre: отправляет `[FREE]` в активную сессию по расписанию через PTY
- Три режима: разовый через интервал, разовый на точное время, повторяющийся
- Настраиваемый шаблон: `<timefromlastmessage>`, `<time>`, `<date>`, `<text>`, `<text?, >`
- Очередь в `~/.vael/heartbeat-queue.json` переживает перезапуск приложения
- Отправка откладывается, пока сессия занята — до 5 минут, затем принудительно
- Запуск блокируется без активного PTY: проверяется живость процесса, а не статус idle

**CLI `vael` — управление из терминала:**

- `vael wake 5min` / `--at 09:00` / `every 30min` — постановка задач в очередь
- `vael hb on/off`, `hb session this`, `hb template` — состояние и настройки модуля
- `vael tg "текст"` — отправка сообщения в Telegram с подтверждением в stdout
- `vael status`, `vael wake list/cancel/clear`
- Команды передаются через `~/.vael/heartbeat-control.json`, опрос раз в секунду

**Интерфейс:**

- Панели Telegram и Heartbeat переписаны: статус модуля, закреплённая кнопка
  сохранения, индикатор состояния PTY выбранной сессии, список активных сессий
- Telegram: определение chat_id через `getUpdates`
- Список модулей в сайдбаре: иконка, название, состояние
- Уведомления: превью карточек, выбор угла, масштаб, звук
- Индикация трафика в обход VPN
- Кнопка разворота свёрнутого сайдбара в шапке

**Под капотом:**

- Модели Claude 5 (Opus 5, Sonnet 5), миграция сохранённых ID
- Общее хранилище сессий `~/.vael/sessions` через junction
- Сбор статистики использования, проверка сетевого маршрута

**Исправлено:**

- Панель Pyre не переключалась между модулями: `activeModuleId` хранился в двух
  независимых состояниях — в `App.tsx` и в `PyreWrapper`
- Флаг `enabled` расходился с реальным состоянием модуля: `start()`/`stop()`
  управляли таймером, но не записывали настройку
- Повторяющиеся задачи теряли отправку при занятой сессии: сдвиг `nextAt` сливал
  отложенную отправку со следующим циклом
- Дрейф интервала: следующее срабатывание считалось от момента доставки вместо
  планового времени
- Автозапуск Heartbeat не срабатывал: на старте приложения PTY ещё не подняты,
  и проверка живости отклоняла запуск
