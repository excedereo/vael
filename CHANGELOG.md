# Vael 2.1.0

**Heartbeat — Ваели будит себя сама:**

- Новый модуль Pyre: печатает `[FREE]` прямо в живую сессию по расписанию
- Три режима: разовая через N минут, разовая на конкретное время, повторяющаяся
- Настраиваемый шаблон фришки: `<timefromlastmessage>`, `<time>`, `<date>`, `<text>`
- Очередь переживает перезапуск — просроченные побудки не сгорают
- Не пишет посреди работы: ждёт, пока сессия освободится, но не дольше 5 минут
- Не запускается без живой сессии — фришка в закрытую сессию уходила бы в никуда

**CLI `vael` — управление из терминала:**

- `vael wake 5min` / `--at 09:00` / `every 30min` — побудки, в том числе себе самой
- `vael hb on/off`, `hb session this`, `hb template` — включение и настройки
- `vael tg "текст"` — сообщение в телеграм, с эхом отправленного
- `vael status`, `vael wake list/cancel/clear`

**Интерфейс:**

- Панели Telegram и Heartbeat переписаны: живой статус, sticky-сохранение,
  индикатор живости сессии, чипы запущенных сессий
- Telegram: кнопка «Определить» подставляет chat_id из последних сообщений боту
- Модули в сайдбаре — крупные плашки с иконкой, названием и состоянием
- Уведомления: превью карточек, выбор угла, масштаб, звук
- Предупреждение, когда трафик идёт мимо VPN
- Свёрнутый сайдбар разворачивается кнопкой в шапке

**Под капотом:**

- Модели Claude 5 — Opus 5 и Sonnet 5, старые ID мигрируют автоматически
- Общее хранилище сессий `~/.vael/sessions` через junction
- Статистика использования, проверка сети

**Исправлено:**

- Панель Pyre не переключалась между модулями: выбранный модуль жил в двух
  копиях состояния — сайдбар показывал одно, панель другое
- Состояние Heartbeat расходилось между CLI и панелью: `start`/`stop` меняли
  таймер, но не настройку
- Повторяющиеся побудки теряли фришку, если сессия была занята в момент
  срабатывания — отложенная сливалась со следующим кругом
- Интервал цикла уплывал: следующий круг считался от момента доставки,
  а не от планового времени
- Автостарт Heartbeat не сработал бы вообще — на старте приложения сессии
  ещё не подняты; теперь модуль ждёт появления живой
